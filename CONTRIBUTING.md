# Contributing to Projet Chess

This repository is a public solo project maintained by its owner. External contributions are welcome via **Pull Requests**, provided they follow the project's guidelines and pass all automated checks—though acceptance is not guaranteed.

## How to Contribute

1. **Fork the repository** and create a feature or fix branch from `main` (for example, `git switch -c fix/opening-book-alignment`).
2. **Set up the development environment** using `pyproject.toml` (Python 3.10+):
   ```bash
   python -m pip install --upgrade pip
   pip install -e ".[dev]"
