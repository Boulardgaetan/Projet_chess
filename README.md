## The goal of the Project

This project is about creating an ICF ELO performance estimator of one game. Indeed, the professional analyzers are mainly not available with every features, which prevents players to have great free estimations.

That's why I intend to propose an open source analyzer.

## Dependencies and Tools
- **Stockfish** : Use for analyzing the positions (`time=0.15`, `depth=14`, `MultiPV=5`). More information on the official webpage of the analyzer : [stockfishchess.org](https://stockfishchess.org/).
